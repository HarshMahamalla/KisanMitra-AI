## 📋 Project Overview

KisanMitra AI is a production-ready, multi-agent farming advisory system that delivers precise, practical, and localized farming advice in both **Hindi** and **English**. Built for Problem Statement No. 14, it demonstrates a complete Supervisor/Orchestrator pattern with 4 specialist AI agents.

## 🚀 Setup Instructions

### Prerequisites
- Python 3.10 or higher
- Node.js 18 or higher
- A Groq API key (free at https://console.groq.com)

---

### Windows Setup

#### 1. Clone / Extract the project
```cmd
cd C:\projects
# Extract kisanmitra-ai folder here
cd kisanmitra-ai
```

#### 2. Create and configure .env
```cmd
copy .env.example .env
notepad .env
```
Edit `.env` and add your Groq API key:
```
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
GROQ_MODEL=qwen3.8-27b
GROQ_VISION_MODEL=qwen3.8-27b
FLASK_SECRET_KEY=any-random-string-here-change-this
FLASK_ENV=development
FLASK_PORT=5000
```

#### 3. Set up Python backend
```cmd
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

#### 4. Set up React frontend
```cmd
cd frontend
npm install
cd ..
```

#### 5. Run backend (Terminal 1)
```cmd
venv\Scripts\activate
python app.py
```
Flask will start on `http://localhost:5000`

#### 6. Run frontend (Terminal 2)
```cmd
cd frontend
npm run dev
```
React will start on `http://localhost:5173`

#### 7. Open in browser
Navigate to `http://localhost:5173`

---

```bash
# Terminal 2 — Frontend
cd frontend && npm run dev
```

## 🔑 Adding Your Groq API Key

1. Go to https://console.groq.com/keys
2. Create a new API key
3. Copy it into your `.env` file:
   ```
   GROQ_API_KEY=gsk_your_actual_key_here
   ```
4. The key is **never sent to the frontend** — all LLM calls are server-side only.

## 🤖 Agent System Prompts

All 5 agent prompts are embedded directly in each service file. Key design decisions:

- **Orchestrator**: Intent classification, bilingual synthesis, empathetic tone rules
- **Crop Advisory**: Organic-first, real generic fertilizer names only, exact dosages
- **Weather/Irrigation**: Rain override rule (>10mm 48h = block all operations), IRRIGATE/DELAY/DRAIN logic
- **Pest Detection**: 3-tier IPM (Cultural → Biological → Chemical last resort), PHI wait-periods
- **Market Advisory**: SELL_NOW/HOLD/DIVERSIFY_MARKET logic, MSP comparison, transport cost analysis

## 🛠 Troubleshooting

| Problem | Solution |
|---------|----------|
| `GROQ_API_KEY is not configured` | Add your key to `.env`, restart Flask |
| `npm run dev` fails | Run `npm install` first in `frontend/` |
| CORS errors in browser | Ensure Flask is on port 5000, Vite on 5173 |
| Slow AI response | Normal — Groq processes 3-4 agents per query; typical time 5–15s |
| Vision model quota | System auto-falls back to text-only analysis |
| `ModuleNotFoundError` | Run `pip install -r requirements.txt` with venv activated |
| Session data lost | In-memory only (v1) — profile saves to localStorage, history is in-session |

### WeatherScene — Reduced Motion

The animated weather scene automatically respects `prefers-reduced-motion`. If the user has enabled "reduce motion" in their OS accessibility settings, a static gradient + simple crop stalks SVG is shown instead of the full animated scene.
